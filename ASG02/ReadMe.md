This 2nd project is to create a library manager.
This 2nd project will let the user add books, look at books, remove books, and change books.

When output is printed, this is what how the program will start:
========== Personal Library Manager =========
Please select an option:
1. Add a book title
2. Remove a book
3. List all book titles
4. Search a book title
5. Save and Exit
Select an option (1-5): 

When the user selected 1: The output will show the user the title to add, the author to add, and the year to add. Then the program says that it has been added and it returns the user to the pogram. Otherwise, it will say the user already added it and returns them back to program.

When the user selected 2: The output will show the user to remove the book using the author's name. Then the program says that the book was successfully removed and 
returns the user back to the program. Otherwise it will say the book wasn't found and returns the user back to the program.

When the user seleccted 3: The output will list all the book titles that were added to the personal library. Then the user is back to the program. 
Otherwise, it will show the user that there are no books within the personal library and returns the user to the program.

When the user selected 4: The output will search a book title the user wants based on the title, author, and year. 
After successfully getting the book requested, the user will be notified the book is in the library and return the user back to the program.
Otherwise, it will say that the book is not in the listing and returns the user to the program.

When the user selected 5: The output will end the program for the user and exit out of the program (just for them to return to the options again...)
